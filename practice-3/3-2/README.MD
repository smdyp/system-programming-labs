Практика 3: Каналы, сокеты, взаимодействие процессов
Задание №2: Именованные каналы FIFO

Реализовать взаимодействие между процессами с помощью именованного канала FIFO.

**Вариант задания**
Через FIFO передать 10 целых чисел. Получатель вычисляет среднее арифметическое и выводит результат на экран.

**Особенность реализации**
Для обеспечения совместимости с WSL (Windows Subsystem for Linux) и файловой системой NTFS, FIFO создаётся в директории `/tmp`, которая полностью поддерживает работу с именованными каналами. Это решает проблему `mkfifo: Operation not supported`, возникающую при работе на диске C: (`/mnt/c/`).

**Используемые системные вызовы**
В программе используются:

- `mkfifo()` — создание именованного канала;
- `open()` — открытие FIFO для чтения/записи;
- `read()` — чтение данных из FIFO;
- `write()` — запись данных в FIFO;
- `close()` — закрытие FIFO;
- `unlink()` — удаление FIFO после использования;
- `fork()` — создание дочернего процесса;
- `wait()` — ожидание завершения дочернего процесса.

Высокоуровневый ввод-вывод `fopen()`, `fprintf()`, `fscanf()` не используется.
