Практика 3: Каналы, сокеты, взаимодействие процессов
Задание №4: Диагностика сетевых соединений

Выполнить диагностику сетевых соединений с помощью системных утилит.

**Используемые утилиты**
В работе используются следующие утилиты:

- `ping` — проверка доступности узла;
- `ss` — получение статистики сокетов;
- `netstat` — отображение сетевых подключений;
- `lsof` — список открытых файлов и портов;
- `curl` — выполнение HTTP-запросов;
- `nc` (netcat) — проверка доступности портов.

**Файлы программы**

commands.txt — сохранённые команды и результаты их выполнения


**Выполняемые команды**

**1. Проверка доступности localhost с помощью ping**
```bash
ping -c 4 localhost

2. Просмотр статистики сетевых сокетов с помощью ss

bash
ss -tuln      # все TCP и UDP сокеты с номерами портов
ss -tan       # все TCP соединения
ss -tunap     # все сокеты с информацией о процессах

3. Просмотр сетевых подключений с помощью netstat
bash
netstat -tuln  # все прослушиваемые порты
netstat -an    # все активные соединения
netstat -i     # статистика по сетевых интерфейсам

4. Просмотр открытых портов с помощью lsof
bash
sudo lsof -i :80      # процессы, использующие 80 порт
sudo lsof -i -P -n | grep LISTEN  # все прослушиваемые порты

5. Выполнение HTTP-запросов с помощью curl
bash
curl -I https://google.com                    # получение только заголовков
curl -o /dev/null -s -w "Время соединения: %{time_connect}s\n" https://google.com

6. Проверка портов с помощью netcat
bash
nc -zv localhost 22    # проверка SSH порта
nc -zv localhost 80    # проверка HTTP порта
nc -zv localhost 8080  # проверка порта 8080
