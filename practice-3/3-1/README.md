# Задание 3-1: Неименованные каналы pipe()

Реализовать взаимодействие между родительским и дочерним процессом с помощью неименованного канала pipe().

**Вариант задания**
Родительский процесс передаёт дочернему процессу массив из 10 целых чисел. Дочерний процесс вычисляет сумму и выводит результат на экран.

**Используемые системные вызовы**
В программе используются:

- `pipe()` — создание неименованного канала;
- `fork()` — создание дочернего процесса;
- `read()` — чтение данных из канала;
- `write()` — запись данных в канал;
- `close()` — закрытие неиспользуемых концов канала;
- `wait()` — ожидание завершения дочернего процесса.

Высокоуровневый ввод-вывод `fopen()`, `fprintf()`, `fscanf()` не используется.

**Файл программы**
Основной файл программы: task.c
