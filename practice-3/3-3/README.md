Практика 3: Каналы, сокеты, взаимодействие процессов
Задание №3: Сокеты TCP

Реализовать взаимодействие клиента и сервера с использованием TCP-сокетов.

**Вариант задания**
Клиент отправляет серверу число, сервер возвращает его квадрат.

**Используемые системные вызовы**
В программе используются:

- `socket()` — создание сокета;
- `bind()` — привязка сокета к адресу и порту;
- `listen()` — ожидание подключений на сервере;
- `accept()` — принятие подключения на сервере;
- `connect()` — подключение клиента к серверу;
- `send()` — отправка данных через сокет;
- `recv()` / `read()` — получение данных из сокета;
- `close()` — закрытие сокета.

Высокоуровневый ввод-вывод не используется.

**Файлы программы**
Основные файлы программы:
server.c — серверная часть
client.c — клиентская часть

text

**Компиляция**
Для компиляции выполнить команды:
```bash
gcc -Wall -Wextra -o server server.c
gcc -Wall -Wextra -o client client.c

**Запуск**
Сначала запустить сервер:

bash
./server
В другом терминале запустить клиента:

bash
./client
Ввести число по запросу клиента.

Ожидаемый результат
На экране клиента должна появиться строка:

Введите число: 5
Число отправлено: 5
Квадрат числа: 25

На экране сервера:
Сервер запущен. Ожидание подключений...
Получено число: 5
Отправлен квадрат: 25

**Краткое описание работы**
Сервер создаёт сокет с помощью socket().
Сервер привязывается к порту 8080 с помощью bind().
Сервер переходит в режим ожидания подключений через listen().
Сервер принимает подключение клиента через accept().
Клиент создаёт сокет и подключается к серверу через connect().
Клиент отправляет число серверу через send().
Сервер читает число через read() и вычисляет квадрат.
Сервер отправляет результат обратно клиенту.
Клиент выводит полученный результат на экран.
Соединение закрывается с помощью close().
