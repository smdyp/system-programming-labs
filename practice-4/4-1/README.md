Практика 4: Память, отображение файлов, демонизация
Задание №1: Динамическая память

Реализовать выделение памяти под строку с использованием динамических функций malloc(), calloc(), realloc(), free().

**Вариант задания**
Выделить память под строку, считать строку с клавиатуры, определить её длину.

**Особенность реализации**
Программа демонстрирует безопасное использование динамической памяти. Память выделяется с помощью malloc() с начальным размером, затем при необходимости расширяется через realloc(). Обязательно проверяется результат каждого выделения памяти. После использования память освобождается через free().

**Используемые системные вызовы**
В программе используются:

- `malloc()` — выделение динамической памяти;
- `realloc()` — изменение размера выделенной памяти;
- `free()` — освобождение памяти;
- `fgets()` — чтение строки с клавиатуры;
- `strlen()` — определение длины строки.

Высокоуровневый ввод-вывод используется только для чтения строки.

**Ожидаемый результат**

Исходная строка: Hello World!

Строка после realloc: Hello World! (скопировано)
Память освобождена.

**Краткое описание работы**
Программа выделяет начальный буфер размером 10 байт через malloc().
Проверяется успешность выделения памяти.
Символ за символом считывается строка с клавиатуры.
При заполнении буфера память расширяется вдвое через realloc().
После завершения ввода определяется длина строки.
Демонстрируется работа calloc() — выделение и обнуление памяти.
Демонстрируется уменьшение памяти через realloc() до точного размера.
Вся выделенная память освобождается через free().
